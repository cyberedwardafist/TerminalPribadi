# core/
Inti desktop. Tidak tahu isi app mana pun.
- `core.js`: state `S`, registry `APPS`/`registerApp`, window manager, tata letak snap, `loadCss`
- `background.js`: animasi canvas (Angin, Hutan, Laut, gambar sendiri). Dipakai Setting lewat `Bg.load()`
- `boot.js`: bangun dock dari app yang terdaftar, jam, buka Home
- `base.css`: variabel tema, menu bar, dock, window, panel snap
